# Start here: deployment for a human or AI agent

Ссылка на этот репозиторий + доступ к целевому аккаунту/серверу + токен бота — отправная точка. Агент определяет доступные ресурсы, генерирует секреты и выполняет команды. Ему также нужно установить **кто владелец** (числовой Telegram ID), какой публичный URL использовать, и на Vercel — подключить постоянную PostgreSQL и минутный планировщик. Эти значения нельзя безопасно угадать из токена бота.

1. Прочитать [AGENTS.md](AGENTS.md). Проверить, новая это установка или обновление.
2. Выбрать [SSH / PHP + SQLite](docs/SSH.md) или [полный Vercel + PostgreSQL](docs/VERCEL.md).
3. Проверить владельца, getMe, HTTPS-домен, доступность базы и планировщика. Владелец должен отправить `/start` боту. Не выбирать первого неизвестного отправителя как owner.
4. Сгенерировать независимые секреты, сохранить приватно, развернуть код, настроить Telegram и cron.
5. Проверить список ниже. Только после этого сообщать, что всё развёрнуто.
6. Собрать [Mac-клиент](docs/MAC.md) на macOS и подключить к API. На Linux/Vercel нельзя собрать нативный AppKit-клиент: исходники доступны, сборка выполняется на Mac или в macOS CI.

## Acceptance checklist

- `health` отдаёт 200 JSON, HTTPS-сертификат действителен.
- `sync` без Bearer, `mini-sync` без initData, webhook без его секрета и Vercel cron без CRON_SECRET возвращают 401.
- Приватные config, data, SQLite sidecars, backups, `.env` и исходники сервера не доступны через HTTP.
- Authenticated POST `/index.php?route=sync` с `{"operations":[]}` возвращает epoch/revision/records. Не печатать задачи или токен в отчёт. Это проверяет настоящую базу, в отличие от health.
- Бот отвечает владельцу на `/today`; посторонний пользователь не получает доступ. Кнопка «Открыть» запускает Production Mini App, не preview/demo URL.
- Создать временную задачу через Telegram; увидеть её в Mini App и Mac. Завершить её `#номер` из Today; проверить общую базу. Удалить только собственную тестовую задачу обычным интерфейсом с возможностью отмены.
- Изменение Mini App появляется в Mac; Mini App после переоткрытия видит сохранённые данные.
- Планировщик действительно вызывает worker/cron каждую минуту; `last_worker` обновляется. Установить временное напоминание на ближайшие 2 минуты и дождаться сообщения при выключенном Mac. Daily Today: 09:00 Europe/Moscow, один раз в день. После первого запуска позже 09:00 первый daily назначается на следующий день.
- Перезапуск процесса/повторный deployment сохраняет epoch, UUID задач и ключи.
- Сохранить приватный client config, endpoint и короткую инструкцию запуска Mac. Токены передавать отдельно, не в публичном отчёте.

## Telegram: что можно настроить автоматически

`deploy/telegram.py` или серверный `admin.php setup-bot` настраивают webhook/polling, команды `/today` и `/app`, default и owner menu button «Открыть». Скрипт не удаляет ожидающие Telegram updates.

Отдельная кнопка Main Mini App на профиле/списке чатов настраивается **в BotFather владельцем**: `/mybots` → нужный бот → Bot Settings → Configure Mini App / Main Mini App → Production Mini App URL. Bot API токена для этой настройки недостаточно. Если у агента нет авторизованного доступа к Telegram владельца, это единственный ручной Telegram-шаг; его нельзя выдавать за выполненный. Ярлык на домашний экран пользователь подтверждает на своём телефоне.

## Обновление и восстановление

Перед обновлением сделайте консистентную резервную копию. SSH-установщик делает `VACUUM INTO` и сохраняет старый код; PostgreSQL — snapshot провайдера/`pg_dump`. Не копировать один `.sqlite` при активном WAL. Не хранить backups внутри web root.

Сохраняйте `epoch`, записи/tombstones, config и секреты. Изменение эпохи останавливает клиентов для защиты данных. Не удалять sync-state клиента, чтобы скрыть эту ошибку. Смена SQLite → PostgreSQL существующей установки требует отдельного переноса **всех таблиц** с сохранением epoch и serial sequences; стандартные инструкции ниже создают новую пустую установку, а не мигрируют личные данные.

После передачи репозитория новую установку можно развернуть независимо от исходного автора: домены, username бота и пути не зашиты в исходный код.
