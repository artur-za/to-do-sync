# Flodo Open · Telegram Mini App

Открывается в Telegram-боте кнопкой **Открыть** или командой `/app`. Общая база с ботом и приложением Mac. Нужен HTTPS; авторизация проверяется сервером по `Telegram.WebApp.initData`, owner_id и сроку подписи. Ни токен бота, ни sync_token в браузер не передаются.

На телефоне колонки Later / This week / Today переключаются вкладками или горизонтальным свайпом списка. Список сдвигается целиком, заливка перемещается между вкладками. Учитывается Reduce Motion. Базовый шрифт задач — 16 CSS px (логические пиксели мобильного экрана), заметки — 14 px. Полосы прокрутки скрыты, вертикальная прокрутка остаётся нативной.

Пять тем выбираются нажатием статуса синхронизации: Белая, Тёмная, Notion, Discord и Telegram. Выбор сохраняется на устройстве. Telegram получает реальные themeParams текущего клиента; вне Telegram используется запасная палитра. Discord использует опубликованные neutral-73/69/66/4/23, opacity-12 и blurple-50 токены тёмной темы, проверенные 30.09.2026 в https://discord.com/assets/952007.753abd23cc85fa72.css. Notion — статическая палитра светлого интерфейса (#ffffff, #f7f7f5, #37352f, #787774, #2383e2); совпадение с текущими внутренними токенами не подтверждено: официальный сайт отклонил автоматическое чтение. Это не обещание точного воспроизведения всех вариантов оформления сторонних приложений.

Создание без даты отправляет задачу в Later. Доступны редактирование, календарь и напоминания, завершение/возврат, поиск, скрытие описаний, закрепление для строки меню Mac, списки с цветами и 30 иконками (выбор изначально свёрнут). Удаление списка сохраняет задачи. Последнее изменение можно отменить из уведомления.

Перенос доступен **только после скрытия описаний** кнопкой сверху. В этом режиме удерживайте карточку и ведите к вкладке или между задачами; мышью достаточно потянуть. Карточка сохраняет исходные ширину и высоту. Когда описания показаны, перетаскивание отключено: горизонтальный жест меняет колонку, вертикальный прокручивает список. Escape отменяет перенос. В меню задачи также есть перенос и изменение порядка.

## Синхронизация

Пока Mini App открыт, сервер опрашивается примерно каждые 4 секунды. Правки хранятся локально и повторяются после восстановления сети. Перезагрузка без сети требует повторного подключения к Telegram для проверки авторизации; сохранённая очередь восстанавливается после входа. Сессия действует до 24 часов от открытия. Заголовок API — X-Telegram-Init-Data; браузер не использует постоянный Bearer-ключ Mac.

Изменения отдельных полей объединяются. При конфликте одного поля сохраняется локальный выбор, обе версии остаются в архиве конфликтов на устройстве (скачивание через кнопку статуса). Удаление имеет приоритет с сохранением конфликтной правки. Редактор не перезаписывает поле, изменённое параллельно с другого устройства, без сообщения пользователю.

Заметки здесь текстовые. Форматирование/RTFD и встроенные изображения Mac сохраняются при правке других полей; изменение самой заметки заменяет их текстом, о чём редактор предупреждает. Системные меню macOS, проверка орфографии AppKit и Dock относятся к настольному приложению. Mini App использует средства ввода и календарь устройства.

## Проверки и разработка

Нет сборщика и сторонних npm-зависимостей. `node model.test.mjs` проверяет слияние, версии, конфликты, удаления, форматированные заметки, завершение и порядок. PHP-тест `server/tests/mini-auth.php` проверяет подпись, пользователя, подмену, повторяющиеся параметры, устаревшие и будущие даты. API проверен на настоящем сервере в обе стороны с работающей Mac-сборкой на временной задаче; задача удалена после теста.

Для локального просмотра: `python3 -m http.server 8123` из этой папки, затем `http://127.0.0.1:8123/?demo=1`. Demo использует только вымышленные задачи в памяти и не вызывает API. Проверены мобильная ширина, создание задачи без даты, списки/иконки, перенос карточки к вкладке и завершение. Физический жест удержания на iPhone отдельно не тестировался.

Для установки скопировать index.php, index.html, app.mjs, gestures.mjs, model.mjs, icons.mjs, style.css, config.mjs и .htaccess в публичную папку mini рядом с index.php API. Обновить серверные http.php и mini-auth.php. Установить меню бота через setChatMenuButton с web_app URL `https://YOUR_DOMAIN/flodo-open/mini/index.php`. Команда /app в bot.php должна указывать туда же. HTTPS обязателен. Не размещайте конфигурацию и базу в mini.

Документация Telegram: https://core.telegram.org/bots/webapps

## Обновление жестов и запуск с телефона

Свайп работает по всей области доски, включая пустое место под задачами, и при скрытых описаниях. Быстрый горизонтальный жест переключает колонки. Движение пальца по вертикали прокручивает список; удержание 350 мс включает перенос только при скрытых описаниях. Мышью компактную карточку можно сразу потянуть по вертикали. TouchEvents обрабатываются отдельно от PointerEvents, чтобы отмена pointer-событий мобильным WebView не обрывала свайп.

Для развёртывания вместе с app.mjs обязательно копировать **gestures.mjs**. Проверки `node gestures.test.mjs` покрывают свайпы, пустую область, компактный режим, вертикальную прокрутку, удержание, отмену и несколько пальцев. Браузером проверены переключение по пустой области, свайп компактной карточки и перенос к вкладке. Физический iPhone в этой сессии недоступен.

В настройках Mini App (статус синхронизации или Settings в меню Telegram) есть **Добавить на главный экран**. Метод `addToHomeScreen()` вызывается только по нажатию пользователя. Проверяются версия Telegram API 8.0+ и `checkHomeScreenStatus`; успешность подтверждается событием homeScreenAdded. Статус added блокирует повторное добавление, unsupported показывает объяснение. Внешний браузер и деморежим не создают ярлык. Иконку предоставляет Telegram из профиля бота; добавление подтверждают на телефоне.

Mini App отключает сворачивание Telegram жестом за содержимое, чтобы оно не перехватывало прокрутку и перенос. Сворачивание за заголовок Telegram остаётся доступно.

Для отдельной кнопки запуска Telegram нужен Main Mini App, настраиваемый владельцем в BotFather: /mybots → нужный бот → Bot Settings → Configure Mini App / Main Mini App → Production Mini App URL. Обычная кнопка «Открыть» внутри чата настраивается автоматически через setChatMenuButton.

## Переносимое развёртывание

Начните с [DEPLOY.md](../DEPLOY.md). Публичные BOT_USERNAME и API_URL находятся в config.mjs и генерируются установщиком/build. Секреты в config.mjs запрещены. Для Vercel сервер и Mini App могут разворачиваться вместе; для отдельного frontend есть deploy/vercel.py.
